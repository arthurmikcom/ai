# Nexus AI

Своя платформа искусственного интеллекта — как ChatGPT, только со всеми лучшими моделями мира в одном месте.

- **Аккаунты**: регистрация по почте, вход через Google или VK ID. Чаты, ассистенты и картинки доступны с любого устройства.
- **Чат** с Claude, GPT, Gemini, Llama, Qwen, Mistral, DeepSeek, Grok и сотнями других моделей. Модель можно сменить прямо посреди диалога.
- **Размышления**: видно, о чём модель думает перед ответом. Кнопка «Думать глубже» — для сложных задач.
- **Картинки в чате**: прикрепите фото или скриншот (или вставьте через Ctrl+V), и модель его разберёт.
- **Генерация изображений**: GPT Image 2.5, Nano Banana Pro, Imagen 4, FLUX, Ideogram, Recraft.
- **Генерация видео**: Veo 3.1, Kling, Seedance, Hailuo, Wan. Задача идёт в фоне — можно уйти со страницы.
- **Свои ассистенты**: создайте своего ИИ с характером, инструкциями и любимой моделью. Есть готовые шаблоны.
- **Тарифы Free и Pro**: дневные лимиты на сообщения, картинки и видео, чтобы публичный сервис не разорил вас на API. Pro оплачивается подпиской через **ЮKassa** (карты РФ, СБП, SberPay) или **Stripe** (международные карты) с автопродлением, либо выдаётся **промокодом** — вообще без платёжной системы. Администраторы работают без лимитов.
- **Свои локальные модели** через [Ollama]: бесплатно, без интернета и ключей.

## Быстрый старт на своём компьютере

Нужен [Node.js] 20 или новее.

```bash
npm install
cp .env.example .env.local   # впишите хотя бы один ключ провайдера
npm run dev
```

Откройте http://localhost:3000 и зарегистрируйтесь. Больше ничего настраивать не нужно: база данных и файлы сами создадутся в папке `.data/`.

## Публикация в интернет (Vercel)

1. **Проект.** Зайдите на [vercel.com](https://vercel.com) через GitHub, нажмите **Add New → Project** и импортируйте этот репозиторий.
2. **База данных.** В проекте откройте **Storage → Create Database → Neon (Postgres)** и подключите её к проекту. Переменная `DATABASE_URL` добавится сама.
3. **Хранилище файлов.** **Storage → Create → Blob**, тип доступа **Private**, подключите к проекту. Добавится `BLOB_READ_WRITE_TOKEN`.
4. **Переменные.** В **Settings → Environment Variables** добавьте:
   - `BETTER_AUTH_SECRET` — 32+ случайных символа (например, результат `openssl rand -base64 32`);
   - ключи провайдеров и `BETTER_AUTH_SECRET` — сначала задеплойте без админа;
   - ключи провайдеров: `ANTHROPIC_API_KEY`, `OPENAI_API_KEY` и т. д.;
   - для приёма оплаты — ключи ЮKassa и/или Stripe и `CRON_SECRET` (см. раздел «Оплата и тарифы»).
5. **Deploy.** Таблицы в базе создадутся при сборке сами. Откройте сайт и зарегистрируйтесь.
6. **Станьте администратором.** В **Настройках** под вашей почтой виден ID аккаунта — скопируйте его в переменную `ADMIN_USER_IDS` и сделайте Redeploy. Администратор работает без лимитов, создаёт промокоды и видит статус провайдеров. (Можно указать почту в `ADMIN_EMAILS`, но она сработает только для подтверждённой почты, например при входе через Google — так нельзя занять чужой адрес простой регистрацией.)

Необязательно:

- **Вход через Google.** В [Google Cloud Console](https://console.cloud.google.com/apis/credentials) создайте OAuth Client ID (Web application). Redirect URI: `https://ваш-сайт/api/auth/callback/google`. Затем задайте `GOOGLE_CLIENT_ID` и `GOOGLE_CLIENT_SECRET`.
- **Вход через VK ID.** Создайте приложение на [id.vk.com](https://id.vk.com/about/business/go). Redirect URI: `https://ваш-сайт/api/auth/callback/vk`. Затем задайте `VK_CLIENT_ID` и `VK_CLIENT_SECRET`.
- **Лимиты.** `FREE_DAILY_CHAT`, `FREE_DAILY_IMAGE`, `FREE_DAILY_VIDEO`: число в сутки или `unlimited`.
- **Закрытая бета.** `APP_PASSWORD` спрашивает общий пароль ещё до входа в аккаунт.

Ответы reasoning-моделей и генерация изображений иногда идут несколько минут. Если длинные ответы обрываются, проверьте лимит длительности функций в вашем тарифе Vercel.

## Оплата и тарифы

Платформа работает и без онлайн-оплаты: у всех есть бесплатный тариф с дневными лимитами. Pro можно включить тремя способами, любые из них сразу.

**1. Промокоды — бесплатно, без регистрации в платёжных системах.** Администратор (см. `ADMIN_USER_IDS`) создаёт коды в **Настройки → Промокоды**: «Pro на 30 дней, 1 активация». Пользователь вводит код на странице «Тарифы» или в настройках. Можно дарить доступ или принимать оплату переводом и отправлять код.

**2. ЮKassa — для России.** Подключение бесплатное, комиссия берётся только с платежей.
1. Зарегистрируйтесь на [yookassa.ru](https://yookassa.ru) (ИП, ООО или самозанятый) и получите `shopId` и секретный ключ: **Интеграция → Ключи API**.
2. Попросите менеджера ЮKassa включить **автоплатежи** (рекуррентные платежи) — без них не будет работать продление.
3. В **Интеграция → HTTP-уведомления** укажите `https://ваш-сайт/api/billing/yookassa/webhook` и отметьте события `payment.succeeded` и `payment.canceled`.
4. Задайте `YOOKASSA_SHOP_ID`, `YOOKASSA_SECRET_KEY`, при необходимости `PRO_PRICE_RUB` (цена в рублях, по умолчанию 990), а также `YOOKASSA_RECEIPTS=true` и `YOOKASSA_VAT_CODE`, если чеки отправляет ЮKassa.
5. Задайте `CRON_SECRET` (любые 16+ случайных символов). Vercel раз в день вызывает `/api/cron/renew` (см. `vercel.json`), и сервер списывает оплату за следующий месяц с сохранённой карты.

Для проверки создайте в ЮKassa **тестовый магазин**: у него свои ключи, автоплатежи уже включены, а оплатить можно тестовой картой `5555 5555 5555 4444` (любой срок и CVC).

**3. Stripe — для международных карт.**
1. В [Stripe](https://dashboard.stripe.com) создайте продукт «Nexus AI Pro» с ежемесячной ценой и скопируйте её ID (`price_...`).
2. В **Developers → Webhooks** добавьте адрес `https://ваш-сайт/api/billing/stripe/webhook` с событиями `checkout.session.completed`, `customer.subscription.created`, `customer.subscription.updated`, `customer.subscription.deleted`, `invoice.paid`, `invoice.payment_failed`.
3. Задайте `STRIPE_SECRET_KEY`, `STRIPE_PRICE_PRO` и `STRIPE_WEBHOOK_SECRET` (`whsec_...`).
4. Включите Customer Portal (**Settings → Billing → Customer portal**): через него пользователи меняют карту и отменяют подписку.

**Важно знать:**
- Перед оплатой пользователь ставит галочку согласия на автопродление, а отключить продление можно в любой момент в настройках. Этого требует закон о подписках (376-ФЗ, действует с 1 марта 2026). Разместите на сайте оферту с условиями подписки и сверьтесь с юристом.
- ЮKassa не подписывает уведомления, поэтому сервер не доверяет их содержимому: по каждому уведомлению он сам запрашивает платёж в ЮKassa и только тогда продлевает Pro. Повторные уведомления не продлевают подписку дважды.
- Если карта отклонена из-за нехватки денег, сервер пробует списать оплату ещё раз на следующий день (до 3 дней после окончания периода). Если банк отозвал разрешение или карта больше не действует, сохранённая карта удаляется, и пользователь видит просьбу оплатить заново.
- Есть сообщения, что API ЮKassa может не принимать запросы с зарубежных серверов. Если оплата не создаётся с Vercel, разместите сайт у российского хостинга.

Лимиты тарифов настраиваются переменными `FREE_DAILY_*` и `PRO_DAILY_*` (число в сутки или `unlimited`).

## Провайдеры моделей

Подключите любых — платформа покажет только тех, чьи ключи заданы.

| Переменная | Что даёт | Где взять |
|---|---|---|
| `ANTHROPIC_API_KEY` | Claude Opus 5.5, Sonnet 5.5, Haiku 5.5, Fable 5.1 | [console.anthropic.com](https://console.anthropic.com/settings/keys) |
| `OPENAI_API_KEY` | GPT-6 Astra, GPT-6.1 Sol и др. + GPT Image | [platform.openai.com](https://platform.openai.com/api-keys) |
| `GEMINI_API_KEY` | Gemini 3.x, Imagen, Nano Banana, видео Veo | [aistudio.google.com](https://aistudio.google.com/apikey) |
| `OPENROUTER_API_KEY` | Сотни открытых и коммерческих моделей | [openrouter.ai](https://openrouter.ai/keys) |
| `DEEPSEEK_API_KEY` | DeepSeek Chat / Reasoner | [platform.deepseek.com](https://platform.deepseek.com/api_keys) |
| `XAI_API_KEY` | Grok | [console.x.ai](https://console.x.ai) |
| `OLLAMA_BASE_URL` | Ваши локальные модели | [ollama.com](https://ollama.com/download) |
| `REPLICATE_API_TOKEN` | FLUX, Ideogram, Recraft, Kling, Veo, Seedance… | [replicate.com](https://replicate.com/account/api-tokens) |

Список моделей не зашит намертво: сервер сверяет подобранные модели с живыми списками провайдеров. Устаревшие модели пропадают сами, а новые появляются в разделе «Показать ещё». На странице изображений и видео можно вписать **любую** модель Replicate в формате `owner/name`.

Для моделей Claude Fable 5.1, Opus 5.5 и Sonnet 5.5 включены резервные модели на стороне сервера (`fallbacks: "default"`). Если модель отклонит запрос из-за срабатывания фильтров безопасности, Anthropic автоматически продолжит ответ другой моделью, а в чате появится пометка об этом.

## «Свой интеллект»: три уровня

1. **Ассистенты** (уже работают). На вкладке «Мои ассистенты» вы задаёте инструкцию: кто это, как он отвечает и что знает. Так устроены GPTs в ChatGPT.
2. **Свои модели на своём компьютере** (уже работают). Установите [Ollama], выполните `ollama pull llama3.2` (или `qwen3`, `deepseek-r1`, `gemma3`…), задайте `OLLAMA_BASE_URL=http://localhost:11434` — модели появятся в списке. Данные никуда не уходят.
3. **Дообучение своей модели** (следующий этап). Берём открытую модель (Llama, Qwen), дообучаем на своих данных методом LoRA и запускаем через Ollama. Обучать модель уровня GPT с нуля стоит десятки и сотни миллионов долларов, поэтому так сейчас делают почти все.

## Устройство проекта

```
src/
  app/                    страницы и API (Next.js App Router)
    login/                вход и регистрация
    api/auth              авторизация (Better Auth)
    api/chat              отправка сообщения: сохраняет, стримит ответ (NDJSON), учитывает лимит
    api/chats, assistants история чатов и ассистенты пользователя
    api/generate          запуск генерации изображений и видео
    api/media             галерея; /api/media/[id] опрашивает фоновые задачи
    api/files             выдача файлов только их владельцу
    api/me                профиль, тариф и остаток лимитов
    api/billing           тарифы, оплата, вебхуки ЮKassa и Stripe, промокоды
    api/cron/renew        ежедневное продление подписок ЮKassa
  components/             интерфейс: чат, выбор модели, студия, ассистенты, настройки
  lib/
    catalog.ts            провайдеры и подобранные модели
    server/db/            схема базы (Drizzle ORM): PostgreSQL или встроенный PGlite
    server/auth.ts        аккаунты, сессии, вход через Google/VK
    server/chat/          адаптеры чата: Anthropic, OpenAI-совместимые, Google
    server/media/         адаптеры генерации: OpenAI, Google, Replicate
    server/storage.ts     файлы: Vercel Blob или папка .data/
    server/usage.ts       дневные лимиты
    server/billing/       тарифы, промокоды, ЮKassa, Stripe
  proxy.ts                без входа — перенаправление на /login
drizzle/                  миграции базы данных
```

Изменили схему в `src/lib/server/db/schema.ts`? Выполните `npm run db:generate`. Новая миграция применится при следующем `npm run dev` или деплое.

Чтобы добавить нового провайдера, опишите его в `src/lib/catalog.ts` и добавьте адаптер в `src/lib/server/`. Если провайдер понимает протокол OpenAI, хватит одной строки с его адресом в `src/lib/server/config.ts`.
